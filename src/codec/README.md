# Обмен

workerProbe.ts описывает только стартовый технический handshake.

`rational.ts` (S1-07) задаёт только числовую границу §13.1 ARCHITECTURE.md:

- `RationalDTO = {n: string, d: string}`;
- `encodeRational(value)` кодирует нормализованный Rational;
- `decodeRational(unknown)` возвращает `valid`, `invalid/INVALID_RATIONAL_DTO`
  либо `technical_error/RESOURCE_EXHAUSTED`.

Декодер строго проверяет собственные поля, целочисленные канонические строки,
положительный знаменатель, НОД = 1 и единственный ноль 0/1. Внешние дроби не
исправляются и не нормализуются молча. JSON-числа, лишние поля, отсутствие знаменателя,
`2/6`, `-0/1`, `1/-3` недопустимы. BigInt в JSON и глобального BigInt.toJSON нет.

Полный codec предметных DTO/каталога/снимка и проверка их ссылок, версий и
бизнес-инвариантов остаются следующими задачами. Неизвестное количество — отдельная
ветвь модели, а не RationalDTO с нулём.
